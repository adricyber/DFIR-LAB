# Tool Matrix

| Área | Herramientas | Función |
|---|---|---|
| Disk | Sleuth Kit, Autopsy, TestDisk/PhotoRec, ExifTool | imágenes, filesystems, recuperación y metadatos |
| Memory | Volatility 3 | RAM forensics |
| Timeline | Plaso, Timesketch | timelines y correlación |
| Endpoint | Velociraptor, Hayabusa | triage, collection, EVTX y hunting |
| Network | Wireshark/tshark, Zeek, Arkime | PCAP y telemetría |
| Malware | YARA, FLOSS | detección y strings |
| Web | ZAP, mitmproxy, ffuf, Nuclei | validación controlada |
| Mobile | MobSF | Android/iOS |
| Access | Tor, WireGuard, proxychains4 | escenarios controlados |

Criterio: ninguna herramienta se instala sin un caso de uso documentado.
