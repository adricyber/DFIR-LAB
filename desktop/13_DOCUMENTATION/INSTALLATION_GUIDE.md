# Guía de instalación

1. Ubuntu LTS actualizado.
2. Clonar DFIR-LAB.
3. Ejecutar `sudo bash install_lab.sh`.
4. Verificar `timedatectl` y confirmar `America/Caracas`.
5. Verificar `/opt/dfir-lab/bin`.
6. Revisar el workspace del Escritorio.
7. Levantar MobSF/Timesketch solamente cuando sean necesarios.
8. Ejecutar casos de prueba con autorización.
