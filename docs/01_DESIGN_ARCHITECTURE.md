# Diseño y arquitectura

Flujo: autorización -> alcance -> baseline -> prueba -> evidencia -> correlación -> resultado -> brecha -> recomendación -> certificación.

Capas: adquisición/evidencia, disco, memoria, timeline, endpoint, red, web, mobile, simulación de acceso, controles WAF/F5/FMC-FTD/antifraude/autenticación/SIEM y reporte.

La red del laboratorio debe estar aislada, con cuentas y datos sintéticos. Las pruebas de evasión/automatización solo se ejecutan dentro del alcance aprobado.
