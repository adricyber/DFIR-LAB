# Procedimiento

1. Solicitud y autorización. 2. Alcance y ventana. 3. Registrar versiones/configuración. 4. Verificar NTP. 5. Crear caso y baseline. 6. Ejecutar prueba. 7. Capturar respuesta. 8. Capturar logs WAF/F5/FMC/SIEM/antifraude. 9. Capturar PCAP/endpoint si aplica. 10. Hash SHA-256. 11. Repetir para reproducibilidad. 12. Registrar resultado y brechas. 13. Restaurar baseline. 14. Cerrar caso.

La evidencia original no se modifica.
