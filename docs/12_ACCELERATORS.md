# Aceleradores 110 / 120 / 130

## 110% — Simulación de riesgo

Capacidades: TOR, VPN, proxy, cabeceras HTTP, User-Agent y emulación controlada. Cada escenario debe tener origen, destino, timestamp, señal esperada y evidencia.

## 120% — Controles multicapa

Correlacionar la misma prueba entre WAF, F5, FMC/FTD, antifraude y SIEM. Registrar detección, decisión, alerta, correlación y evidencia.

## 130% — Certificación permanente

Convertir el laboratorio en gate previo a producción: nueva funcionalidad/cambio -> selección de casos -> ejecución -> evidencia -> informe -> aprobación -> cambio.

Indicadores: cobertura, casos ejecutados, reproducibilidad, hallazgos, tiempo de remediación y reincidencia.
